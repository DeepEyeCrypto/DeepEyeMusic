**What's new in v3.0.1.97**

- **Personalization + cancellation hardening (D1/D5/D6)**
  - Feed generation fencing in `PersonalizationRepositoryImpl` — stale `buildFeed` results from a previous account are discarded.
  - `SmartTubeEngine` content fetch now rethrows `CancellationException` (never swallows cancellation into a fallback/empty).
  - `ContentFetcher` cancel-propagation guard.

- **D7 FEmusic contract + OMEGA typed music states**
  - `InnerTubeRemoteClient.fetchMusicHomeShelves` now throws typed failures (`MusicShelfFailureReason`, `InnerTubeMusicUnavailableException`), keeps 401 auth-rescue on the auth path, and propagates cancellation.
  - `MusicViewModel` uses `collectLatest` + suspend load and surfaces honest **reauth / unavailable / empty** states — no silent empty, no generic filler.
  - Account-switch generation fencing: a late response from the previous account never overwrites the new session's state.

- **FEL same-song-loop + prefetch guard**
  - `QueueManager`: a single-item queue in `Repeat ALL` now yields `null` so autoplay resolves a *different* track (intentional single-track repeat still via `Repeat ONE`).
  - `AutoplayRepository`: cached autoplay queues scrubbed through the current/history guard.
  - `PlayerController`: atomic prefetch guard so the 100 ms poller no longer fires duplicate `/next` fetches.
  - `NowPlayingScreen`: a11y polish (`contentDescription`).

- **Tooling**
  - D7 status-only debug probe receiver (debug variant only, no secrets) + `D7ProbeContractTest`.
  - G1GC for the Gradle build.
