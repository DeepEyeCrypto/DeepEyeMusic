### For our 70 MB APK, always also set:
```sh
export REA_JADX_OPERATION_TIMEOUT_MS=600000   # default 120000 is not enough for DeepEyeMusicPro APK
```

## Usage

```sh
export REA_JADX_MCP_JAR="$HOME/.local/share/rea/android/jadx-headless-mcp-0.7.1-all.jar"
export REA_JADX_OPERATION_TIMEOUT_MS=600000
cd /Users/enayat/Documents/DeepEyeMusicPro

# Inspect APK (manifest, permissions, classes)
rea inspect-android-package app/build/outputs/apk/debug/app-debug.apk --format json

# Analyze a specific class
rea analyze ...   # (see `rea --help` for full command list in 6.x)

# MCP server mode
rea --mcp
```
