# Plan: V4A DSP Cards 2-Column (2-2) Grid Layout

## Goal
Switch the V4A DSP Engine module cards grid from 3 cards per row to exactly 2 cards per row (2-2 layout) on landscape/tablet viewports, providing wider cards with better touch targets for sliders and knobs.

## Current Context / Assumptions
- Screen: `DSPScreen.kt` (`com.deepeye.musicpro.ui.dsp.DSPScreen`)
- When the app is in landscape/wide mode (`isWideScreen`), `ModulesGrid` uses `columns = GridCells.Adaptive(ContentBounds.dspModuleMinSize)` (180.dp), which lays out 3 cards per row on the device viewport (~800dp+).
- The user requested: "V4A DSP me jo card hai 3 -3 usko 2-2 kar de".

## Proposed Architecture / Approach
- Update `ModulesGrid` in `app/src/main/java/com/deepeye/musicpro/ui/dsp/DSPScreen.kt` to use `columns = GridCells.Fixed(2)` instead of `GridCells.Adaptive(ContentBounds.dspModuleMinSize)`.
- Update `ContentBounds.kt` docs/values accordingly if referenced.
- Verify the build and deploy to device, taking a screenshot of the DSP screen to confirm 2 cards per row.

## Step-by-Step Implementation Tasks

### Task 1: Update `ModulesGrid` in `DSPScreen.kt`
- **File**: `app/src/main/java/com/deepeye/musicpro/ui/dsp/DSPScreen.kt`
- **Action**: In `ModulesGrid` composable (line 411-421), replace `columns = GridCells.Adaptive(ContentBounds.dspModuleMinSize)` with `columns = GridCells.Fixed(2)`.
```kotlin
@Composable
```

- None; `GridCells.Fixed(2)` is standard for dual-column control modules in Compose and ensures 2 cards per row across landscape widths.
