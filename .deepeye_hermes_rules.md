# DeepEyeMusicPro — Enterprise Android Architectural Directives

## 1. Jetpack Compose Stability & Zero-Recomposition Rules
- All UI state classes must be annotated with `@Stable` or `@Immutable`.
- Never read high-frequency mutating states (playback position, visualizer FFT data, continuous scroll/drag deltas) inside the **Composition Phase**.
- Defer high-frequency state reads strictly to the **Draw Phase** (`Modifier.drawWithCache`, `Canvas { ... }`) or **Layout Phase** (`Modifier.layout`, `Modifier.offset { ... }`) via lambda suppliers (`() -> T`).
- Replace standard Kotlin collection types (`List<T>`, `Set<T>`) in State classes with `ImmutableList<T>` / `persistentListOf()` from `kotlinx.collections.immutable` to avoid compiler stability de-optimization.

## 2. Touch Interception & Parent Scroll Hierarchy (Anti-Stutter)
- Standard Compose gesture detectors (`Modifier.scrollable`, `LazyColumn`, `detectHorizontalDragGestures`) operate on `PointerEventPass.Main`.
- Any horizontal child slider or custom fader inside a scrollable parent (`LazyColumn`, `ModalBottomSheet`, `HorizontalPager`) MUST hook into `PointerEventPass.Initial` using `Modifier.preventParentScrollOnDrag()` or `Modifier.consumeHorizontalDrags()`.
- Eagerly consume pointer events (`change.consume()`) on `PointerEventPass.Initial` as soon as displacement occurs to starve the parent container of scroll deltas and eliminate touch-slop race condition cancellations (`onDragCancel`).

## 3. Hardware-Accelerated Rendering & Memory Management (Anti-OOM)
- High-res artwork decoding must use GPU-backed `Bitmap.Config.HARDWARE` on Android 8.0+ (API 26+) to keep pixel buffers out of Java heap memory.
- Bound Coil Memory Cache to $\le 25\%$ of available application heap.
- High-frequency visualizers (FFT audio curves, geometric shapes) must render on a dedicated `Canvas` with isolated state reads to maintain 60–120 FPS on Mali/Adreno GPUs.

## 4. Coroutines, IPC & StateFlow Conflation
- High-frequency playback position emissions ($\le 16\text{ms}$ windows) and FFT audio streams must use `.conflate()` to prevent Main Looper message queue saturation.
- Real-time DSP/touch parameter updates to hardware audio engines must execute with $0\text{ms}$ latency while disk persistence (DataStore/Room) is debounced by $200\text{ms}$.
- Isolate all Room database transactions, heavy JSON parsing, and network extraction strictly to `Dispatchers.IO` or `Dispatchers.Default`.

## 5. Android 14+ Foreground Service Lifecycles
- `MusicPlayerService` must explicitly declare and enforce `FOREGROUND_SERVICE_TYPE_MEDIA_PLAYBACK`.
- Never block the Main Thread during `onCreate()` or `onStartCommand()`. Post immediate foreground notifications before initiating asynchronous metadata resolution.
- Always execute deterministic teardown (`serviceScope.cancel()`, `player.stop()`, `mediaSession.release()`) inside `onDestroy()`.
